# الصلاة — AL-SALAH (MAS)

تطبيق مواقيت صلاة أندرويد (Kotlin + Jetpack Compose) لجميع محافظات مصر، يعمل دون إنترنت ودون حساب.

## البناء التلقائي (GitHub Actions)
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتوى هذا المجلد (يجب أن يظهر `.github/workflows/build-apk.yml` في الجذر).
2. أي push على فرع `main` يشغّل البناء، أو من تبويب **Actions → Build Android APK → Run workflow**.
3. بعد النجاح: افتح تشغيل الـ workflow ونزّل الـ artifact باسم **`alsalah-final-apk`** (يحتوي `app-debug.apk`).
   المسار داخل البناء: `app/build/outputs/apk/debug/app-debug.apk`.
4. الـ workflow يشغّل أولًا اختبارات الوحدات، ثم يبني النسخة.

## البناء محليًا
JDK 17 و Android SDK (منصة 36) و Gradle 8.13+:
```
gradle :app:testDebugUnitTest
gradle :app:assembleDebug
```
(لا يوجد Gradle Wrapper في المستودع؛ شغّل `gradle wrapper --gradle-version 8.13` مرة واحدة إن أردته.)

## ما تم تنفيذه
- **المواقيت**: محرك فلكي (معادلة الزمن، الميل الشمسي، زوايا الساعة) — الهيئة المصرية (فجر ١٩٫٥° / عشاء ١٧٫٥°) + رابطة العالم الإسلامي + كراتشي + ISNA، العصر شافعي/حنفي، تصحيح يدوي لكل صلاة، التوقيت الصيفي حسب قواعد المنطقة الزمنية لكل تاريخ، معالجة منتصف الليل.
- **المواقع**: ٢٧ محافظة (عاصمة كل محافظة)، GPS لمرة واحدة عند الطلب، إحداثيات يدوية، حفظ الموقع.
- **التنبيهات**: AlarmManager (دقيق عند السماح)، جدولة متدحرجة ٣ أيام، إعادة جدولة بعد: إعادة التشغيل، تغيير الوقت/التاريخ/المنطقة، تحديث التطبيق، تغيّر إذن المنبّه، وتغيير الإعدادات/الموقع. إعدادات مستقلة لكل صلاة (قبل الصلاة: ٥–٣٠ أو مخصص، عند الوقت: تكبير/نغمة/صامت، اهتزاز).
- **التكبير**: «الله أكبر، الله أكبر» فقط (لا أذان كامل) عبر محرك النطق العربي (TextToSpeech) داخل خدمة foreground من نوع mediaPlayback، مع بديل نغمة الإشعار. زر «اختبار الإشعار والصوت» يستخدم نفس مسار التنبيه الحقيقي.
- **القبلة**: زاوية القبلة (٢١٫٤٢٢٥، ٣٩٫٨٢٦٢)، بوصلة حية من Rotation Vector مع تصحيح الانحراف المغناطيسي، تنبيه المعايرة، بديل يدوي عند غياب المستشعر.
- **الأذكار** (٦ أقسام + المفضلة)، **المسبحة** (تراجع، أهداف، جلسات، حفظ محلي)، **التقويم الهجري** (أم القرى + تعديل ±٢ + مناسبات)، **دعاء اليوم**، **الإعدادات** (مظهر فاتح/داكن/نظام، ١٢/٢٤ ساعة، …).
- **Widgets**: صغير/متوسط/كبير. العد التنازلي بـ Chronometer على مستوى النظام (بلا تحديث كل ثانية)، ويتحدث عند كل صلاة.
- **الأداء**: ساعة تتحدث كل ثانية فقط أثناء ظهور الشاشة وفقط مكوّن العد التنازلي يعاد رسمه؛ مستشعر البوصلة يُسجَّل أثناء ظهور الشاشة فقط؛ لا خدمات خلفية دائمة؛ لا تتبع GPS مستمر.

## حدود وقرارات صريحة (اقرأها)
- **لم يُبنَ ولم يُشغَّل على جهاز.** البيئة التي كُتب فيها المشروع بلا Android SDK ولا إنترنت. تحقّقت من الحساب الفلكي بنسخة Python مطابقة للخوارزمية (القاهرة ١٣ نوفمبر ٢٠٢٦: ظهر ١١:٣٩، قفزة التوقيت الصيفي ≈ ٥٩ دقيقة) وفحصت الأقواس والموارد ثابتًا، لكن **أول بناء على GitHub هو أول ترجمة حقيقية**؛ قد تظهر أخطاء ترجمة صغيرة تحتاج إصلاحًا.
- **اختبارات الوحدات** (`PrayerEngineTest`) اختبارات سلامة منطقية (نطاقات للقاهرة، ترتيب المواقيت لكل المحافظات في كل الشهور، DST، منتصف الليل، القبلة). **ليست مطابقة رسمية** لجداول الهيئة المصرية — أضف أسطرًا من جدول رسمي لمدينة وتاريخ وقارنها بتسامح دقيقة.
- **المراكز والقرى**: لا توجد مجموعة بيانات موثّقة دون اتصال هنا، فلم أخترع سجلات. المتوفر: ٢٧ عاصمة محافظة بإحداثيات تقريبية + GPS + إدخال إحداثيات يدوي. لإضافة المراكز استورد بيانات موثّقة (مثل GeoNames) في `EgyptLocations.kt`.
- **صوت التكبير**: لا يوجد تسجيل مرخّص مرفق، لذا يُستخدم محرك النطق العربي في الجهاز. إن أردت تسجيلًا: ضع ملفًا مرخّصًا في `res/raw` وشغّله بـ MediaPlayer داخل `TakbeerService`.
- **التخزين**: SharedPreferences بدل DataStore/Room (تغطي كل الحاجة الحالية بأقل حجم وأبسط وصول من الـ receivers). 
- **الزجاج**: تأثير «زجاجي» بطبقات شبه شفافة وحدود متدرجة؛ لا يوجد ضبابية خلفية حقيقية (blur) حفاظًا على الأداء على الأجهزة الضعيفة.
- **حدود أندرويد**: لا يمكن تجاوز وضع الصامت/عدم الإزعاج أو التحكم بمستوى صوت النظام؛ شريط الصوت يؤثر على صوت نطق التكبير فقط. على أندرويد ١٢+ يجب أن يسمح المستخدم بـ«المنبّهات والتذكيرات» لتصل التنبيهات في الدقيقة (الإعدادات ← أذونات وموثوقية التنبيهات).
- **بطاريات الشركات**: شاومي/هواوي/أوبو/فيفو/سامسونج قد توقف التطبيق في الخلفية. اسمح للتطبيق بالعمل دون قيود البطارية وفعّل التشغيل التلقائي. مرجع: dontkillmyapp.com
- **ألوان الـ widgets** تتبع وضع النظام (فاتح/داكن) وليس خيار المظهر داخل التطبيق (قيد في RemoteViews).
- **المحتوى الديني**: الأذكار والأدعية بنصوصها ومصادرها المعروفة، وتحتاج **مراجعة أهل العلم/تدقيقًا لغويًا** مقابل مصدر مطبوع موثوق قبل النشر العام. لا تُنشر قبل هذه المراجعة.
- حالة الواجهة عند التنقل بين التبويبات: بيانات المستخدم محفوظة، لكن موضع التمرير لا يُحفظ.
